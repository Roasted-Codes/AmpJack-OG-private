# Changelog

## 0.1.0-preview.1

- First packaged release of **OG-AmpJack**: wired Xbox One / Series controller support for Halo 2 (TU1.5 / u803) on the original Xbox, as an XBMC trainer.
- Shipped module is the hardware-tested rumble-capable build (internal W65R): input and rumble on the modern pad, original controller unaffected.
- Trainer renamed to `OG-AmpJack.{xbtf,bin}` with display title **OG-AmpJack** and one option, *Enable controller support*. Tested on console: input and rumble confirmed with this release.
- Earlier development trainers (AmpJack43, AmpJack63, AmpJack65 wake-only) are historical and no longer maintained.
- Known limits documented: Halo 2 u803 only, replug workaround for a dark pad, IGR unverified, no headset audio yet.
