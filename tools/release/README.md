OG-AmpJack 0.1.0
================

Wired Xbox One / Series controllers in Halo 2 on an original Xbox, as an
XBMC trainer.

Install
1. FTP Trainers/OG-AmpJack.xbtf and Trainers/OG-AmpJack.bin to E:\Trainers\.
   Keep the two files together and do not rename them.
2. In XBMC: Halo 2 -> Update trainer list -> select OG-AmpJack ->
   tick "Enable controller support".
3. Plug the pad into port 2 and launch Halo 2 from XBMC.

Needs stock Halo 2 TU1.5 (u803) and a passive Xbox-to-USB cable. The trainer
checks the game executable and does nothing if it does not match.

To remove it, untick the option or delete both files from E:\Trainers\.
